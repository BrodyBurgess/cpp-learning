# Constructors and Virtual Destructors

This exercise demonstrates how constructors and destructors work with inheritance in C++.

**Concepts practiced:**
- Base and derived class constructors
- Constructor and destructor execution order
- Dynamic object allocation using `new`
- Virtual destructors and `override`
- Releasing memory using `delete`
- Resetting a pointer to `nullptr`

The program creates a Skeleton object through an Enemy pointer and safely destroys it using a virtual destructor.
